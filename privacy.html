Privacy Policy

Effective date: January 1, 2024

PlannerX is built on a simple principle: your data is yours. The app has no backend, no account system, and no network communication of any kind. This policy explains exactly what that means in practice.

1No data collection

PlannerX does not collect, transmit, store, or process any personal data on any server. Specifically:

  • No account or registration is required to use the app.
  • No usage analytics or telemetry are sent anywhere.
  • No crash reports are automatically uploaded.
  • No advertising identifiers are read or shared.
  • The app never initiates any network request.
PlannerX is fully functional with no internet connection. A network connection is never required, requested, or used.

2Local storage

All data created within PlannerX — saved dive plans, app settings, and UI state — is stored exclusively as JSON files in the app's private documents directory on your device. This directory is managed by the operating system and is not accessible to other apps without explicit user action (e.g. a file-sharing export you initiate).

When you export a PDF or use the system share sheet, the resulting file is handled entirely by your device's operating system. PlannerX has no visibility into where you send or save that file.

Uninstalling PlannerX removes all locally stored data in accordance with the policies of the respective platform (Android, iOS, etc.).

3Device permissions

PlannerX may request the following platform permissions:

Permission Purpose
Storage / Files Write exported PDF files to device storage when you use the share/print function.

No other permissions are requested. The app does not access your location, camera, microphone, contacts, or any other sensitive device resource.

4Third-party services

PlannerX does not integrate any third-party SDK, analytics library, advertising network, or crash reporting service. The only external code included is the Flutter framework and its standard packages (pdf, printing, path_provider), none of which send data to external servers.

5Children

Because PlannerX collects no personal information from anyone, there are no special considerations for users under 13 (COPPA) or under 16 (GDPR). The app is intended for use by certified technical divers; responsible adult supervision is assumed.

6Changes to this policy

If this policy ever changes, the updated version will be published at plannerx.garzuu.com/privacy with a new effective date. Because we collect no contact information, we cannot notify you directly — please check this page if you have questions.

7Contact

Questions about this policy? Open an issue or start a discussion on the GitHub repository.
