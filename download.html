macOS

DMG · Signed & Notarized

  1. Download the DMG using the button on the right or with curl.

  2. Open the DMG — double-click the downloaded file to mount it.

  3. Drag RuntimeX into Applications — drag the app icon onto the Applications shortcut inside the DMG window.

  4. Launch — open RuntimeX from Launchpad or Spotlight. Because the app is signed and notarized by Apple, no security warning will appear.

  5. Eject the DMG — right-click the mounted volume in Finder and eject it.

Homebrew Cask

macOS · Terminal

  1. Install Homebrew if you don't have it yet — see brew.sh.

  2. Add the tap — this registers the RuntimeX cask repository with Homebrew.

  3. Install the cask — Homebrew downloads and installs RuntimeX automatically.

  4. Update later — run brew upgrade --cask runtimex when a new version is available.

  5. Uninstall — run brew uninstall --cask runtimex to remove it completely.

Terminal commands

brew tap garzuu/runtimex
brew install --cask runtimex
Open tap repo
The tap is auto-updated by CI after each release. The SHA256 in the cask always matches the file at /downloads/RuntimeX-macos.dmg.

Windows

Installer EXE · x64

  1. Download the installer using the button on the right.

  2. Run the installer — double-click RuntimeX-windows.exe. Windows may show a SmartScreen prompt; click More info → Run anyway.

  3. Follow the wizard — choose the install folder (default: C:\Program Files\RuntimeX) and optionally create a desktop shortcut.

  4. Launch — find RuntimeX in the Start menu or on the desktop.

  5. Uninstall — use Add or Remove Programs in Windows Settings.

Linux

tar.gz · x64

  1. Download the tarball and verify the SHA256 checksum if needed.

  2. Extract it to a folder of your choice, for example ~/.local/share/runtimex.

  3. Run the binary — execute ./runtimex inside the extracted folder. You can add it to your $PATH or create a desktop entry.

  4. Optional: create a launcher — create a .desktop file in ~/.local/share/applications/ for Gnome/KDE integration.

Download & install

curl -LO https://runtimex.garzuu.com/downloads/RuntimeX-linux.tar.gz
mkdir -p ~/.local/share/runtimex
tar -xzf RuntimeX-linux.tar.gz -C ~/.local/share/runtimex
~/.local/share/runtimex/runtimex

Android

APK · arm64

  1. Enable Unknown sources — go to Settings → Apps → Special app access → Install unknown apps and enable it for your browser or Files app.

  2. Download the APK from the button on the right, directly on your Android device.

  3. Open the APK — tap the downloaded file in your notifications or Files app and confirm the install prompt.

  4. Launch — find RuntimeX in your app drawer.

  5. Update — repeat steps 2–3 with the new APK; Android will update the existing install in place.

Download

# download directly on device or transfer via USB/ADB
adb install RuntimeX-android.apk
