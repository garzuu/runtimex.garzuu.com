Download RuntimeX for macOS and Windows

RuntimeX is an offline-first technical dive planner. Download the DMG or Windows installer directly from this site, or install it from the terminal with Homebrew Cask.

Choose your install path

Both routes point to binaries built in the site repo from the private source repo.

macOS DMG

Download the DMG from this site, open it, and drag RuntimeX into Applications.

curl -LO https://runtimex.garzuu.com/downloads/RuntimeX-macos.dmg
Download DMG

Windows EXE

Download the Windows installer directly from this site. It is built from the private source repo and published here.

curl -LO https://runtimex.garzuu.com/downloads/RuntimeX-windows.exe
Download EXE

Homebrew Cask

Prefer the terminal? Use the dedicated tap repository and keep updates simple.

brew tap garzuu/runtimex
brew install --cask runtimex
Open tap repo

Verify the release with the SHA256 files in the downloads folder if you want to confirm the download before opening it.
