  1. 01Choose DMG or Homebrew.
  2. 02DMG — open the downloaded file and drag RuntimeX into your Applications folder.
  3. 03Homebrew — copy the command, paste it into Terminal and press Enter.
  4. 04Blocked by Gatekeeper on first launch? Go to System Settings → Privacy & Security → Open Anyway.
  1. 01Download and run the installer.
  2. 02SmartScreen may appear — click More info → Run anyway.
  3. 03Follow the wizard. Find RuntimeX in the Start menu when done.
